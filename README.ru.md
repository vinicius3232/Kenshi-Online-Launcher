## ✨ Что это

**Kenshi Online** добавляет в Kenshi кооперативный мультиплеер (изначально игра только одиночная). Проект состоит из:

- **Лаунчер** — настольное приложение (Electron + React), которое устанавливает мод, управляет сервером и запускает игру.
- **Мод KenshiMP** — набор плагинов на C++, встраивающих сетевой слой в движок игры (Ogre/ENet) и синхронизирующих персонажей, позиции и чат между игроками.

Игроки соединяются через **VPN (Radmin VPN)**, создавая виртуальную локальную сеть — без необходимости открывать порты на роутере.

> ✅ **Автоматическая установка:** при нажатии **Установить мод** лаунчер сам кладёт файлы интерфейса (`.layout`) в `data/gui/layout/`, активирует мод в `data/__mods.list` и регистрирует плагин в `Plugins_x64.cfg`. Никакого копирования файлов вручную — именно это самая частая ошибка при ручной установке (не открывается меню **F1** / чат).

## 🚀 Установка (пошагово)

### 1️⃣ Скачайте установщик
Скачайте [`Kenshi-Online-Setup-1.0.2.exe`](https://github.com/vinicius3232/Kenshi-Online-Launcher/releases/download/v1.0.2/Kenshi-Online-Setup-1.0.2.exe).

> ⚠️ Браузер может предупредить, что файл «не проверен». Это нормально (установщик без платной цифровой подписи). Нажмите **Сохранить / Всё равно сохранить**.

### 2️⃣ Запустите установщик
- Дважды щёлкните по `.exe`.
- Если Windows покажет окно **«Windows защитил ваш компьютер»** → **Подробнее** → **Выполнить в любом случае**.
- Далее: **Далее → Установить → Готово**.

### 3️⃣ Установите мод
- Откройте **Kenshi Online** (ярлык на рабочем столе).
- Нажмите **Установить мод** (Install Mod) и дождитесь подтверждения.

### 4️⃣ Подключитесь к VPN (только если хостинг не смог сам открыть порт)
- Откройте **Radmin VPN**.
- Войдите в сеть группы (спросите у хоста **название сети** и **пароль**).
- Убедитесь, что статус **«Подключено»**.

### 5️⃣ Играйте
- В лаунчере подключитесь к серверу хоста.
- В игре:
  - **F1** → меню мультиплеера
  - **Enter** → чат

🎉 Готово!

## 🏗️ Техническая архитектура

```
┌─────────────────────────────────────────────────────────┐
│                    KENSHI ONLINE                          │
├─────────────────────────────────────────────────────────┤
│  Лаунчер (Electron + React 19 + Vite)                     │
│   └─ Ставит мод, поднимает сервер и запускает игру        │
├─────────────────────────────────────────────────────────┤
│  Мод KenshiMP (C++)                                       │
│   ├─ KenshiMP.Core.dll    → плагин Ogre (сеть в игре)    │
│   ├─ KenshiMP.Server.exe  → выделенный сервер (ENet/UDP) │
│   └─ KenshiMP.Injector.exe → регистрирует плагин         │
├─────────────────────────────────────────────────────────┤
│  Транспорт: ENet (UDP)  •  Сеть: Radmin VPN              │
└─────────────────────────────────────────────────────────┘
```

**Компоненты:**
- `KenshiMP.Core` — плагин, загружаемый Ogre (`Plugins_x64.cfg`); отвечает за синхронизацию состояния, интерполяцию и обработку пакетов.
- `KenshiMP.Server` — авторитетный выделенный сервер; управляет подключёнными игроками, рассылкой позиций и чатом.
- `KenshiMP.Injector` — регистрирует плагин и настраивает путь лаунчера.

## ❓ Частые проблемы

| Проблема | Решение |
|----------|---------|
| Никого не вижу в VPN | Все должны быть в **одной** сети Radmin VPN. |
| Игра сама закрывается | Откройте лаунчер заново и нажмите **Установить мод** ещё раз. |
| Антивирус удалил файл | Добавьте папку Kenshi Online в исключения и скачайте заново. |
| Синий экран Windows при запуске | **Подробнее → Выполнить в любом случае**. |
