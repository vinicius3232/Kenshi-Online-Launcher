# 🎮 Kenshi Online — Guia do Jogador (passo a passo)

Guia simples para jogar Kenshi em co-op com os amigos. **Todos os jogadores devem seguir os mesmos passos.**

---

## ✅ Antes de começar (todos)

| Você precisa de | Onde conseguir |
|-----------------|----------------|
| 🎮 **Kenshi** instalado (Steam) | Steam |
| 🪟 **Windows 10 ou 11** (64-bit) | — |
| 🌐 **Radmin VPN** (grátis) | https://www.radmin-vpn.com/ |
| ⬇️ **Instalador do Kenshi Online** | Link do Discord / GitHub Release |

> ⚠️ **Importante:** todos precisam usar **a versão mais recente** do instalador. Se alguém instalou antes, **reinstale** com o link atual — versões antigas não funcionam.

---

## 1️⃣ Instalar o launcher

1. Baixe o `Kenshi-Online-Setup-1.0.2.exe`.
2. O navegador pode avisar que o arquivo "não é verificado" → **Manter / Manter mesmo assim**.
3. Duplo clique no `.exe`.
4. Se aparecer **"Windows protegeu o computador"** → **Mais informações** → **Executar assim mesmo**.
5. **Avançar → Instalar → Concluir**.

---

## 2️⃣ Instalar o mod

1. Abra o **Kenshi Online** (atalho na Área de Trabalho).
2. Clique em **Instalar Mod**.
3. Espere a confirmação de sucesso.

> Se o Kenshi estiver aberto, **feche o jogo** antes de clicar em Instalar Mod.

---

## 3️⃣ Entrar na VPN (Radmin)

1. Abra o **Radmin VPN**.
2. Entre na **mesma rede** do grupo (peça **nome da rede** e **senha** ao host).
3. Confirme o status **Conectado** (verde).

> Todos têm que estar na **mesma rede Radmin**, senão um não enxerga o outro.

---

## 4️⃣ ⭐ Começar o jogo do jeito CERTO (passo mais importante)

Para os jogadores se verem, **todos precisam estar no mesmo mundo "Multiplayer"**. Existem só dois jeitos válidos:

### Opção A — Começar um mundo novo (recomendado na 1ª vez)
**TODOS** fazem o mesmo:
1. No Kenshi: **Novo Jogo**.
2. Escolha o start chamado **"Multiplayer"**.
3. Entre no mundo (espere carregar o jogo de verdade, com os personagens na tela).

### Opção B — Continuar um mundo já começado
- **Todos** carregam **o MESMO save** que foi criado a partir do start "Multiplayer".

> ❌ **Não funciona:** cada um carregar o seu save individual antigo (de uma campanha single-player). Vocês até conectam ("2 jogadores"), mas **não se veem**. Tem que ser o start **"Multiplayer"** ou o **mesmo** save dele.

---

## 5️⃣ Conectar

1. Com o **mundo já carregado** (você dentro do jogo):
2. **Host:** sobe o servidor pelo launcher.
3. **Demais jogadores:** entram no servidor do host pelo launcher.

🎉 Pronto — vocês devem se ver e se mover juntos no mundo!

---

## 🎛️ Controles dentro do jogo

| Tecla | Ação |
|-------|------|
| `F1` | Abre/fecha o menu do multiplayer |
| `Enter` | Abre o chat |
| `Tab` | Lista de jogadores |

---

## ❓ Deu problema?

| Problema | Solução |
|----------|---------|
| Conecta mas **não vejo o outro jogador** | Os dois iniciaram pelo start **"Multiplayer"**? (Passo 4). Esse é o erro mais comum. |
| Não vejo ninguém na VPN | Todos na **mesma rede** do Radmin VPN? (Passo 3) |
| O jogo fecha sozinho ao abrir | Reabra o launcher → **Instalar Mod** de novo. Feche o Kenshi antes. |
| Antivírus apagou o arquivo | Adicione a pasta do Kenshi Online como exceção e baixe de novo. |
| "Windows protegeu o computador" | **Mais informações → Executar assim mesmo** (instalador sem assinatura paga, é normal). |
| Instalei uma versão antiga | **Reinstale** com o link mais recente. |

---

## 🧭 Resumo rápido (cola)

1. Instalar launcher → 2. **Instalar Mod** (jogo fechado) → 3. Entrar na **mesma rede Radmin** → 4. **Novo Jogo → start "Multiplayer"** (TODOS) → 5. Host sobe servidor, resto conecta.

**Regra de ouro:** se conectou mas não se veem → quase sempre é porque alguém **não** usou o start **"Multiplayer"**.
